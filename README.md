## Hello!! Welcome to my passion project !!
__________

Jinks is an online music-streaming service built to put artists and users first

We prioritize on finding a way to make the user expierenece as curated to the listener and artist discorvery as possible

We specialize in finding you local artists that are to match your listening profile

We do abide by the following rules:

1.   Anti-Ai Music, detection system that will not allow AI music to be uploaded and will be flagged against the artist, 3 strike system until they are kicked off the system
2.  Blockchain System to link artist to own their royalties entirely
3.  The listener will be able to own they're information entierly and see how they're data is being manipulated to curate their listening expierence
